AI search behavior
- Qwen performs structured role interpretation; deterministic parsing reconciles explicit constraints before returning the existing SearchIntent shape.
- Explicit source text controls experience, location, skills, salary, work mode, employment type, exclusions, precision and posted-date limits.
- Known stack acronyms (MERN, MEAN, PERN and MEVN) map to canonical roles and their component skills.
- Optional null values are omitted at the Python-to-NestJS boundary to match the existing Zod contract.
- The configured local model default is qwen3.5:2b-q4_K_M. Confirm the root .env points to the same installed Ollama tag; the patch does not overwrite .env or secrets.
